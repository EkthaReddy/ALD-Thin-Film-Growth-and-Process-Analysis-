# ALD-Thin-Film-Growth-and-Process-Analysis-
Analyzed simulated Al₂O₃ thin-film data to examine the relationship between deposition cycles, film thickness and growth per cycle (GPC). Also, compared assumed temperature-dependent growth behavior and evaluated five-point wafer thickness uniformity using mean, standard deviation and nonuniformity calculations.
